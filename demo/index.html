Overture Maps Foundation community · Digital Corridors concept pilot · strategy brief

One road segment. One ID. Every dataset.

Every interstate in the United States on one keyed Overture network — with live 511/WZDx events from over twenty state DOT feeds, fetched by your own browser (directly where the publishing host allows it, and through a thin allowlisted relay where it doesn't — the same pattern USDOT could run once, nationally) and conflated to GERS IDs on this page, right now, plus live traffic sensors and DOT cameras. Each state keeps its own schema and linear referencing; the GERS ID is only the join key. The dark network is the invitation: every state that publishes a feed can light up. This page is the pipeline

No server sits behind this map. Your browser fetches the states’ own public feeds and performs the GERS conflation itself — route-aware nearest-segment matching against real Overture geometry, with method and snap distance on every join. If the feeds are unreachable, the page falls back to a labeled snapshot.

Freight plans around it, like aviation does

Airlines plan every departure around weather and NOTAMs on one national picture. With every state’s events on one keyed network, a dispatcher can route a 2,000-mile trip around construction before the truck rolls — and corridor operators can coordinate like flow management.

A return path for vehicle fleets

AV and ADAS fleets already detect cones, lane shifts, workers, and hard braking. Referenced to GERS, those observations confirm state feeds — and surface what the feeds missed. The Fresno tab shows that loop as a concept.
